【三步搞定】

第1步：点击安装
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 右键点击 "PDD运营工具-安装程序.bat"
2. 选择 "以管理员身份运行"
3. 等待安装完成（会自动下载依赖，需要几分钟）

第2步：启动应用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 双击 "start-dev.bat"
2. 等待两个窗口打开

第3步：开始使用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 看到 "PDD运营工具" 窗口打开 ✓
2. 左上角显示 "✓ 已连接" ✓
3. 就可以开始使用了 ✓

【就这么简单！】

✅ 添加店铺
   菜单 → 店铺管理 → 添加店铺 → 输入信息 → 保存

✅ 同步商品
   菜单 → 商品管理 → 选择店铺 → 点击同步

✅ 查看数据
   菜单 → 数据统计 → 选择店铺 → 查看各种数据

✅ 定时任务
   菜单 → 定时任务 → 创建任务 → 设置Cron表达式

【遇到问题？】

❌ 提示需要Node.js
   → 下载安装：https://nodejs.org/
   → 重启电脑

❌ 提示需要PostgreSQL
   → 下载安装：https://www.postgresql.org/
   → 重启电脑

❌ 比特浏览器无连接
   → 确保比特浏览器已启动
   → 检查配置文件 backend\.env 中的地址

❌ 无法创建数据库
   → 打开命令行（管理员），输入：
      psql -U postgres
      CREATE DATABASE pdd_tool;
      \q

【配置调整】

如需修改配置（数据库密码、端口等）：
1. 编辑 backend\.env 文件
2. 重新运行 start-dev.bat
