## 数据流

### 店铺登录流程

1. **用户操作** → 点击"添加店铺" → 选择登录方式
2. **前端** → 调用后端 API 创建任务
3. **后端** → 调用比特浏览器 API，打开登录窗口
4. **比特浏览器** → 打开拼多多登录页面
5. **用户操作** → 完成登录
6. **比特浏览器** → 通知后端登录完成
7. **后端** → 自动提取页面数据（店铺名、ID等）
8. **后端** → 保存到数据库
9. **前端** → 实时更新显示

### 数据抓取流程

1. **用户** → 点击"刷新"或自动任务触发
2. **前端** → 创建抓取任务
3. **后端** → 添加到任务队列
4. **任务执行器** → 调用比特浏览器 API
5. **比特浏览器** → 打开拼多多页面
6. **比特浏览器** → 注入脚本提取数据
7. **后端** → 解析数据，存储到数据库
8. **前端** → 定时轮询任务状态
9. **前端** → 更新显示

## 数据库设计

### 核心表

- **users** - 用户信息
- **shops** - 店铺信息
- **shop_groups** - 店铺分组
- **products** - 商品列表
- **statistics** - 统计数据
- **tasks** - 任务队列

### 数据脱敏

- 手机号：存储加密，显示脱敏（130****1234）
- 姓名：存储加密，显示脱敏（张*）

## 模块职责

### 前端（Tauri + React）

- UI 展示
- 用户交互
- 本地状态管理（Zustand）
- API 调用
- 实时更新

### 后端（Node.js + Express）

- 业务逻辑处理
- 数据库操作
- 任务队列管理
- API 接口
- 身份认证

### 比特浏览器集成层

- 浏览器自动化
- 页面数据提取
- 自动化操作（点击、填表等）
- 事件通知

## 技术选择理由

- **Tauri** vs Electron: 包体积小（5MB vs 150MB），性能更好
- **React**: 开发效率高，组件生态丰富
- **PostgreSQL**: 支持复杂查询，商用稳定
- **Express**: 轻量级，快速开发
- **比特浏览器**: 防检测能力强，API完善

## 安全考虑

- JWT 令牌认证
- 敏感数据加密存储
- CORS 跨域保护
- SQL 参数化查询防 SQL 注入
- 环境变量隐藏敏感信息

## 扩展性

- 模块化设计，易于添加新功能
- 任务队列可扩展为分布式系统
- 数据库可迁移到云服务
- 支持多用户场景
