【安装步骤】

1️⃣ 准备环境
   - 安装 Node.js 16+ (https://nodejs.org/)
   - 安装 PostgreSQL 13+ (https://www.postgresql.org/)
   - 安装 比特浏览器 (已有)
   - 重启电脑

2️⃣ 运行安装
   📌 右键点击 install.bat
   📌 选择"以管理员身份运行"
   
   脚本会自动：
   ✓ 检测 Node.js 和 PostgreSQL
   ✓ 安装所有依赖
   ✓ 创建配置文件

3️⃣ 配置数据库
   📌 创建数据库（管理员命令行运行）：
   
   psql -U postgres
   CREATE DATABASE pdd_tool;
   \q

4️⃣ 配置应用
   📌 编辑 backend\.env 文件：
   
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=pdd_tool
   DB_USER=postgres
   DB_PASSWORD=123456  ← 改成你的密码
   BITBROWSER_API_URL=http://127.0.0.1:54345

5️⃣ 启动应用
   📌 双击 start-dev.bat
   
   会自动打开两个窗口：
   - 后端服务
   - 前端应用

【快速测试】

✅ 测试1：检查后端
   在浏览器打开：http://localhost:3001/api/health
   
   看到绿色 "status": "ok" ✓

✅ 测试2：检查前端
   应该看到 PDD运营工具 窗口打开
   左上角显示 "✓ 已连接" ✓

✅ 测试3：添加店铺
   - 点击"店铺管理"
   - 点击"添加店铺"按钮
   - 输入店铺名称
   - 点击"添加"
   - 看到列表中出现新店铺 ✓

✅ 测试4：定时任务
   - 点击"定时任务"菜单
   - 点击"创建定时任务"
   - 填写信息
   - 看到任务列表 ✓

✅ 测试5：数据导出
   - 在店铺列表点击"导出"
   - 生成 CSV 文件 ✓

【常见问题】

❌ 端口3001被占用
   解决：修改 backend\.env 中的 PORT=3002

❌ PostgreSQL连接失败
   解决：检查密码是否正确，确保PostgreSQL服务启动

❌ 比特浏览器无连接
   解决：检查 BITBROWSER_API_URL 是否正确

❌ 权限错误
   解决：以管理员身份运行所有脚本
